# Лабораторная работа №6 — 3D-модели

Проект реализован на **C# (.NET 8) и Avalonia UI 11**.

## Возможности

- Отображение правильных многогранников: тетраэдр, гексаэдр, октаэдр, икосаэдр, додекаэдр.
- Аффинные преобразования через матрицы 4x4:
  - перенос;
  - поворот вокруг X, Y, Z;
  - масштабирование относительно центра модели;
  - отражение относительно XY, XZ или YZ;
  - поворот вокруг произвольной прямой.
- Перспективная и аксонометрическая проекции.
- Загрузка и сохранение моделей в формате Wavefront OBJ.
- Построение фигуры вращения по образующей.
- Построение поверхности `z = f(x, y)`.
- Управление мышью: перемещение — поворот модели, колесо — масштабирование относительно центра.

## Основные классы

| Класс | Назначение |
|---|---|
| `Point3` | Точка в трёхмерном пространстве |
| `Polygon` | Многоугольник / грань |
| `Polyhedron` | Многогранник: вершины и грани |
| `Matrix4` | Матрицы аффинных преобразований 4x4 |
| `ObjImporter`, `ObjExporter` | Загрузка и сохранение OBJ |
| `Camera` | Перспективная и аксонометрическая проекции |
| `Renderer` | Отрисовка граней с сортировкой по глубине |
| `RevolutionBuilder` | Построение фигуры вращения |
| `SurfaceBuilder` | Построение графика функции двух переменных |

```bash

```

```bash

```

## Формат OBJ

Программа поддерживает строки:

```obj
v x y z
f i1 i2 i3 ...
```

Индексы вершин в OBJ начинаются с `1`. Поддерживаются также записи вида `f 1/1/1`, `f 1//1` и отрицательные индексы.

## Пример проверки

1. Запустите приложение.
2. Нажмите **Гексаэдр**.
3. Введите смещение `1; 0; 0` и нажмите **OK**.
4. Введите угол `45`, выберите ось `Y`, нажмите **Повернуть**.
5. Введите масштаб `1.5` и нажмите **Масштабировать**.
6. Переключите проекцию на **Аксонометрическая**.
7. Нажмите **Построить** в разделе «Фигура вращения».
8. Введите `sin(x) * cos(y)` и постройте график поверхности.
9. Сохраните модель в `.obj`, затем загрузите её снова.

## Математическая основа

Все преобразования выполняются в однородных координатах:

\[
p' = pM,
\]

где \(p = (x, y, z, 1)\), а \(M\) — матрица преобразования \(4 \times 4\).

Поворот вокруг произвольной прямой реализуется последовательностью:

\[
T(-A) \cdot R_Y \cdot R_X \cdot R_Z(\varphi) \cdot R_X^{-1} \cdot R_Y^{-1} \cdot T(A).
\]

Перспективная проекция использует деление на глубину, а аксонометрическая является параллельной изометрической проекцией.
